Ce dépôt contient un tutoriel écrit sous la forme d'un notebook Jupyter
permettant de montrer comment manipuler des données d'IRM pondérées en
diffusion. Le code montré ici a avant tout une vocation pédagogique et ne
représente pas de manière exhaustive toutes les étapes de pré-traitement qu'on
s'attent à retrouver dans une chaine de traitement d'images pondérées en
diffusion.
